Facilitation reminders
The repeating unit
Lesson (30 min) → Independent case file (15 min) → Table discussion (20 min) → Full-room debrief (15 min) → Break. Breaks are earned, not scheduled. The table that finishes first waits; the room moves together.
Tent card mechanism
Two questions face-down at each table before independent work begins. Students flip them when done. Q1: "What decision did your table make and why?" Q2: "What is the strongest argument for the option you didn't choose?"
Opening a lesson
Move 1 is a cold call problem that requires the read-ahead to answer. If tables can't engage with it, the read-ahead didn't happen. Use that gap as data, not as a correction moment. The case file will surface it.
Debrief anchor
Circulate during independent work and listen for Decision 2 splits. Open the full-room debrief there -- not at Decision 1 (usually consensus) or Decision 3 (usually doctrine). The split is where learning happens.
Day 1 compression
CF01 and CF02 run as a paired discussion, not two separate 60-minute blocks. Saves 30-40 minutes. Present both case summaries, then run one combined table discussion and one debrief covering both decisions.
Read-ahead accountability
Replace the Day 1 icebreaker with a table challenge: three questions pulled directly from the read-aheads. Tables that did the reading answer them. This establishes the expectation without embarrassing individuals.
